# Ibn Turka VN — Version 3.0 (archived)

Frozen snapshot as of commit `f2a65f6`, before the v4 systems overhaul specified
in [`../visual-novel/PROPOSAL.md`](../visual-novel/PROPOSAL.md). Version 3.0's
distinguishing traits: short (~14-word) name-specific option reasoning, themed
ending journal, 8 endings — but with the systems gaps the v4 design review
found (20/40 dead flags, cosmetic skill tree, no in-game premise introduction).

Kept playable side-by-side with
[`../visual-novel/`](../visual-novel/index.html) (current),
[`../visual-novel-v2/`](../visual-novel-v2/index.html), and
[`../visual-novel-v1/`](../visual-novel-v1/index.html). Not maintained going
forward.
