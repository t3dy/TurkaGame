# Ibn Turka VN — Version 2.0 (archived)

Frozen snapshot of the prototype as of commit `48b1168`, before the choices
writing overhaul that shortened and re-specified option reasoning for Version 3.0.
Kept playable side-by-side with [`../visual-novel/`](../visual-novel/index.html)
(current) and [`../visual-novel-v1/`](../visual-novel-v1/index.html) (original
short-label version).

This folder is not maintained going forward. Version 2.0's distinguishing trait
was long (2-4 sentence) per-option reasoning; Version 3.0 kept the reasoning but
cut it to roughly a third of the length and tied it more specifically to named
people, texts, and institutions from `docs/BIOGRAPHY.md` wherever the historical
record supports it.
