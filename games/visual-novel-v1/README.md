# Ibn Turka VN — Version 1.0 (archived)

Frozen snapshot of the prototype as of commit `7bf20cd`, before choice options
gained expanded reasoning/detail text (commit `05cc1f6`). Kept playable
side-by-side with the current version at
[`../visual-novel/`](../visual-novel/index.html) so the "before" of that change is
still visitable, not just described in a commit message.

This folder is not maintained going forward — new writing, gameplay, and graphics
work all lands in `../visual-novel/`. If you're here to fix a bug, check whether it
also exists in the current version and fix it there first; this snapshot stays
frozen deliberately.
