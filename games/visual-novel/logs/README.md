# Simulated Playthroughs

Complete, readable transcripts of Ibn Turka's life as the game actually plays it —
one for every ending, plus several failure and edge states. Each log records every
scene as written, the choice taken, **what else was on offer**, **what was locked
and why**, skill changes, the consequence, and the final ending with its epilogue.

Generated by driving the real game modules headlessly:

```bash
node tools/run-simulations.mjs
```

Everything here is reproducible — the random sweep is seeded, so re-running
produces identical results.

## The eight endings

| # | Log | Ending |
|---|---|---|
| 01 | [Vindicated Martyr](01-vindicated-martyr.md) | Holds firm, transmits the work whole, dies defiant — closest to the documented history |
| 02 | [Source Code of Empire](02-source-code-of-empire.md) | The platform outlives the man and becomes the cosmology of six court cultures |
| 03 | [New Brethren Endures](03-new-brethren-endures.md) | Ideas survive scattered across students, unsystematized |
| 04 | [Lost Legacy](04-lost-legacy.md) | Integrity kept, work lost — a failure that is not a moral failure |
| 05 | [Rehabilitated Judge](05-rehabilitated-judge.md) | Bends, but the judicial reputation outlasts the scandal |
| 06 | [Quiet Compromise](06-quiet-compromise.md) | Bent the knee with nothing to be rehabilitated by |
| 07 | [Solitary Sage](07-solitary-sage.md) | Withdrawal — survives, influences nothing in his lifetime |
| 08 | [Court Philosopher](08-court-philosopher.md) | A lifetime of caution defuses the third inquisition entirely |

## Failure and edge states

| # | Log | What it demonstrates |
|---|---|---|
| 09 | [The door closed in Act II](09-failure-lockout.md) | Defecting from Iskandar Sultan removes the patron-favour defence eight choices later — and the scene text *narrates* the absence rather than silently hiding it |
| 10 | [The floor of investment](10-failure-minimal-scholar.md) | Declining every optional skill grant still ends at 5 points in one science: there is no "refuse the occult sciences" path |
| 11 | [Always the first option](11-edge-first-option.md) | What the game gives a player who clicks through without reading |
| 12 | [Always the last option](12-edge-last-option.md) | The opposite baseline — takes every unlocked signature moment, and still loses the work by keeping the papers |
